# OBSkipNight
Minecraft PaperMC plugin to provide a command to skip the night. Always something<br>
the players on our PlayerServers wants to do. Minimal config. Just three properties<be>
which can be set through the command.<br>

/skipnight help - show the usage<br>
/skipnight settings - will show the current configuration values<br>
/skipnight owneronly - toggles who can run the command. owner/op only, or anyone<br>
/skipnight broadcast - toggle on/off skip message to all players or just initiator<br>
/skipnight timer <seconds> - set the countdown timer before skip<br>

Compiled for 26.1.2 and Java 25
